# 投資の誘いチェック (scam-check-jp)

SNS・LINE・マッチングアプリで届いた投資やお金の話を貼ると、
**警察庁などが公開している詐欺の典型**に当てはまるかを調べる、無料の Web ページです。

- **貼った文は端末の外に送りません。** サーバーも AI も使っていません (固定の規則だけで判定)。
- 当てはまった特徴ごとに、理由と出典 (警察庁 SOS47 など) を表示します。
- どの結果でも、警察相談専用電話 **#9110** へ案内します。
- もっと詳しく考えたい人のために、自分の AI (ChatGPT・Claude など) に貼る文面を作れます。運営者は AI の費用を負担せず、個人情報も預かりません。

## 判定の3段階

| 表示 | 条件 |
|:--|:--|
| 詐欺の可能性が高い | 「引き出しに手数料を払え」「当局に止められている」に当たる、または特徴が3つ以上 |
| 注意 | 特徴が1〜2つ |
| 規則に当たらなかった | 特徴が0。**「安全」とは表示しない** (新しい手口は規則に無いため) |

規則の中身は [rules.mjs](rules.mjs) にあり、1つずつ理由と出典が付いています。

## 限界

- **初版の検出率は低いです (測定済み、2026-11-06)。** 警察・自治体・消費者庁などが引用した詐欺の文 60 件のうち、
  何かの特徴を指摘できたのは **14 件 (23%、95% 信頼区間 14〜35%)** でした。事前に決めた合格の線 60% を下回り、**不合格**です。
  正規の業者・金融庁の文 48 件を「詐欺の可能性が高い」と誤判定した数は 0 件でした。
  詳細: [eval/PREREG.md](eval/PREREG.md) (事前登録) / [eval/DEVIATION.md](eval/DEVIATION.md) / [eval/results_primary.json](eval/results_primary.json)
- 見逃しの多くは、(1) 「保釈金がいる」「旅費を送って」のような、理由をつけてお金を求める文、
  (2) 「愛してる」「日本の友達が欲しい」のような、ロマンス詐欺の最初の段階の文 (文だけでは普通の会話と区別できない)、
  (3) 「損はしない」「手数料が100万円かかります」のように、規則の言い回しから少しずれた文、でした。
  次の版は、言い回しの照合だけでなく「会ったことがあるか」「お金を求められたか」などの状況を尋ねる形に変え、**新しく集めたデータ**で測り直します。
- **状況を尋ねる版 (v2) も不合格でした (2026-11-06)。** 詐欺の事例は 48/48 を指摘できましたが、
  正規の業者のお知らせ 40/40 も「詐欺の可能性が高い」と判定しました。「わからない」を危険側に倒した設計の欠陥と、
  公開ページから読み取った答えでは質問の良し悪しを測れないという測定の限界が原因です。v2 は公開していません。
  詳細: [eval-v2/RESULT.md](eval-v2/RESULT.md) / コードはブランチ `v2-experiment`
- 言い回しを変えた文は見逃します。規則に当たらなかったからといって安全ではありません。
- 詐欺かどうかを決める道具ではありません。判断の手助けです。

## 誤検出の記録

- 2026-11-06: 規則を書いた直後の試しで、正規の業者のお知らせ (「出金手数料を改定します」「出金は手数料無料です」) を
  「詐欺の可能性が高い」と判定した。「出金」と「手数料」が並ぶだけで当てていたため。
  警察庁の記述 (引き出しのための手数料を**要求する**) に合わせ、同じ文に「払え・入金しろ」という要求がある時だけ当てるよう直した。
  同時に「ビットコインを買ってみた」「ゴルフ大会の参加費」の誤検出も直した。
  これらの文は自動テストにはまだ入っていない (テストファイルを後から書き換えない運用のため、次の版で別に追加する)。

## 使い方 (開発者向け)

```bash
node --test test/rules.test.mjs
```

```bash
python -m http.server 8000
```

`index.html` は ES module を読むので、ファイルを直接開かず、上の簡易サーバーか GitHub Pages で開いてください。

## 貢献

- 新しい手口の誘い文句 (**公開された出典つき**) と、誤検出した普通の文を歓迎します。
- 被害の詳細や個人情報は Issue に書かないでください。
