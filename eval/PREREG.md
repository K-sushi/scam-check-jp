結果を見る前にこのファイルと `eval/score.mjs` を commit する。commit 後は、どちらも結果を見てから変えない。

## 対象
- 判定する規則: commit `370ea10` の `rules.mjs` (初版、公開した版)。測定が終わるまで規則を変えない。
- 判定の関数: `check(text)` の `verdict` (`high` / `caution` / `no-match`)。

## データ
- 集めるのは、**規則を見ていない別の担当** (subagent)。担当には `rules.mjs` もこのリポジトリも見せない。
- 詐欺の文 (`label: scam`): 警察・自治体・消費者庁・国民生活センター・金融庁などの公開ページに、**実際に送られた文として引用されている**文。
  - **除外**: 規則の出典にした 2 ページ (警察庁 SOS47「SNS型投資詐欺」、茨城県警察「SNS型投資・ロマンス詐欺」)。
  - 1 つの文は 1 件。同じ文の重複は 1 件に数える。
- 詐欺でない文 (`label: benign`): 利用者が実際に貼りそうな、正規の投資・お金の文。
  金融庁登録の証券会社・銀行・暗号資産交換業者のお知らせ、金融庁・日本証券業協会の投資の解説、投資を話題にした普通の会話の例。
- 目標件数: 各 40 件以上、60 件で打ち切り。

## 指標 (主指標は 2 つ)
| 指標 | 定義 | 合格の線 |
|:--|:--|:--|
| **検出率** (主) | 詐欺の文のうち `verdict != no-match` の割合 | 0.60 以上 |
| **強い誤判定率** (主) | 詐欺でない文のうち `verdict == high` の割合 | 0.05 以下 |
| 強い検出率 (参考) | 詐欺の文のうち `verdict == high` の割合 | 線なし |
| 誤検出率 (参考) | 詐欺でない文のうち `verdict != no-match` の割合 | 線なし |

- 合否は点推定で決める。Wilson の 95% 信頼区間を必ず併記する。
- 種類別 (投資 / ロマンス / その他) の内訳は記述だけで、合否に使わない。

## 停止と判定の規則
- 詐欺の文が 30 件未満、または詐欺でない文が 30 件未満なら、合否を出さず「件数不足」と報告する。
- 主指標 2 つとも線を満たせば PASS。どちらかを外せば FAIL。
- FAIL でも規則はこの測定の中では直さない。直した版は、**今回のデータとは別に新しく集めたデータ**で測り直す。
- 今回のデータで見つかった見逃し・誤検出は記録する。それを使って直した規則の成績を、今回のデータで報告しない (同じデータで直して同じデータで測ると、成績が良く見えるだけになるため)。
