# 事前登録からのずれ (採点の前に記録、2026-11-06)

1. **詐欺の文が 80 件集まり、登録の上限 60 件を超えた。**
   収集担当には「条件に合うものは全部入れる」と指示したため。
   - 主の判定: id 順 (集めた順) の先頭 60 件 (`corpus_primary.jsonl`、投資 30 / ロマンス 21 / その他 9) と、正規の文 48 件全部。
   - 参考: 80 件全部 (`corpus_all.jsonl`) の結果も併記する。合否には使わない。
   - この決め方は、採点の結果を見る前に決めた。
2. **「実際に届いた文」かどうかの確度が混ざっている。**
   公的機関のページには、実際の受信文と、手口を説明するための例文が混ざる (収集担当の報告)。
   区別せずに全件を使う。結果の解釈では「公的機関が引用した典型文での成績」として読む。
3. **短い断片 (例: 「必ず儲かる」) が全体の約 3 分の 1 ある。** そのまま使う。
4. **category「その他」に警察官のなりすまし (投資・ロマンス以外) の 3 件が入っている。** 登録は種類を限定していないので、外さない。
